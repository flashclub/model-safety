01 / CAPABILITY

对手的工具箱，已经换代

不需要 futurism——只列已发生的事。威胁能力不再依赖「人写 exploit」：能自主读代码、找漏洞、串联攻击步骤的系统，已经拿过冠军、找过零日、开过机器人。

Google Big Sleep（Project Zero × DeepMind）用大模型做变体分析，在 SQLite 中发现一个此前未公开的可利用漏洞——被广泛视为 AI 首次在广泛使用的真实软件里找到全新零日。

02 / ATTACK SURFACE

系统的裂缝：六类已经打开的口子

LLM 系统把「自然语言」变成了指令边界，而鉴权、WAF、沙箱都管不到这一层。以下每一类都有公开案例或可复现研究——不是理论推演。

PI / 提示注入

直接与间接提示注入

网页、邮件、工单、文档里的几行字，就能劫持 agent 的后续行为——模型无法可靠区分「数据」与「指令」。

已发生：GitHub 官方 MCP 服务器被报告注入弱点（2025-05）；受测 agent 94% 失守。来源 ↗

SUPPLY / 工具链投毒

MCP 工具投毒与描述篡改

恶意工具描述、安装后突变（rug pull）的指令，随「装一个插件」进入系统，还能横向污染同会话里的其它服务器。

已发生：工具投毒进入 CVE 编号（CVE-2025-54136），云安全联盟 2026-06 发布 AI 技能供应链攻击通报。来源 ↗

MEM / 记忆投毒

长期记忆与状态污染

一次注入写进 agent 的长期记忆，之后每一次会话都带着恶意指令运行——攻击者早已离开现场。

已发生：Unit 42 在 Amazon Bedrock 上演示了经间接注入静默污染长期记忆的完整路径。来源 ↗

EXFIL / 数据外带

借「正常工具」外带数据

诱导 agent 调用看起来完全合法的日志、总结、分享工具，把敏感数据包装成正常流量送出去。

新类别：2026 年学术界提出 Log-to-Leak 等纯提示级隐私攻击，仅靠 prompt 即可驱动外带。来源 ↗

AUTHZ / 混淆代理

拿着你的全部权限行事

agent 通常以用户身份持有整套凭据。一次成功的注入 ≈ 一次账号接管，且发生在「用户自己发起的会话」里。

研究结论：78 项研究的综述中，受测编码 agent 全部可被注入导向凭据窃取路径。来源 ↗

ACT / 自主行动与支付

会花钱的 Agent 是新金库

当 agent 能下单、转账、签名（如 x402 一类机器支付协议），「注入一条指令」就直接等于「资金损失」，攻击回报空前明确。

趋势：能力与权限同步膨胀——能动的资产越多，评估窗口越贵。

传统安全边界 LEGACY
防火墙管网络、鉴权管身份、沙箱管代码执行。它们都默认：指令来自受控通道。
LLM 系统的边界 UNTRUSTED BY DEFAULT
系统的「指令面」包含了全网任意文本。任何进入上下文的内容，都必须当作不可信输入处理——这一点，多数团队还没有可验证的证据。
